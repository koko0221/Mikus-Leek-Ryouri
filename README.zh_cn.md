## 概要：
《初音的葱料理》是以「初音未来」与「葱」为主题发想的料理模组。

使用原版为主的内容作为延伸，加入了一系列与「葱」相关的作物、料理、武器、药水、效果⋯⋯，当然也少不了各式小彩蛋！
