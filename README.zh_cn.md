# 简介：
《初音的葱料理》是一款以「初音未来」与「葱」为主题创作的料理模组。
以原版内容为基础进行扩展，加入了一系列与「葱」相关的作物、料理、武器、药水、效果……当然也少不了各种小彩蛋！
