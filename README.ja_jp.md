## 概要：
『初音のネギ料理』は、「初音ミク」と「ネギ」をテーマにした料理系MODです。

バニラ要素をベースに拡張し、「ネギ」に関連する作物、料理、武器、ポーション、効果など、さまざまなコンテンツを追加しています……もちろん、たくさんの小ネタやイースターエッグも含まれています！
