# 概要：
《初音的蔥料理》是以「初音未來」與「蔥」為主題發想的料理模組。
使用原版為主的內容作為延伸，加入了一系列與「蔥」相關的作物、料理、武器、藥水、效果⋯⋯，當然也少不了各式小彩蛋！
